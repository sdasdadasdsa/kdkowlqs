# ORBIT — тестовый сайт

Готовая адаптивная HTML-страница с космической анимацией, случайными сообщениями и сменой цветовой темы.

## Публикация на GitHub Pages

1. Откройте [Settings → Pages](https://github.com/sdasdadasdsa/kdkowlqs/settings/pages).
2. В **Build and deployment** выберите **Source: Deploy from a branch**.
3. Установите **Branch: main**, папка **/(root)** и нажмите **Save**.
4. После успешной публикации сайт будет здесь: https://sdasdadasdsa.github.io/kdkowlqs/

Главная страница — `index.html` в корне репозитория. Сервер и установка пакетов не требуются.
